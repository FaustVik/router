# .var Directory

Эта директория содержит временные файлы, кеши и отчеты, которые генерируются во время разработки и тестирования.

## Структура

```
.var/
├── phpunit/         # Кеш PHPUnit
├── phpstan/         # Временные файлы PHPStan
├── coverage/        # Отчеты о покрытии кода тестами
└── README.md
```

## Содержимое

### phpunit/
Кеш PHPUnit для ускорения повторных запусков тестов.

### phpstan/
Временные файлы и кеш PHPStan для статического анализа кода.

### coverage/
HTML отчеты о покрытии кода тестами. Генерируются командой:
```bash
composer test-coverage
```
Затем открывайте `.var/coverage/index.html` в браузере.

## Важно

⚠️ Всё содержимое этой директории (кроме README.md и .gitkeep) игнорируется Git'ом и не попадает в репозиторий.

Эти файлы генерируются автоматически и специфичны для каждой машины разработчика.
